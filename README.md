# fake_check_parser1

Сбор и проверка ботов VK по данным [Ботнадзора](https://botnadzor.org).

Нужен только Python 3.9 или новее, ставить ничего не надо.

## Файлы

- `botnadzor.py` — скрипт
- `botnadzor_accounts_csv.zip` — полная база ботов в CSV (около 600 тыс. аккаунтов). Свежую версию можно в любой момент скачать командой `dump`.

## Команды

### Скачать всю базу ботов

```
python3 botnadzor.py dump -o accounts.csv
```

Скрипт берёт те же данные, что и расширение Ботнадзора: каждый аккаунт с категорией, подкатегорией и регионом.

### Проверить аккаунт через сайт

Скрипт открывает `https://botnadzor.org/account/id{N}` и разбирает страницу:

```
python3 botnadzor.py site 3333
python3 botnadzor.py site 3333 --json
python3 botnadzor.py site --range 3300-3400 --only-bots -o site.csv
```

Что он достаёт со страницы:

- бот или нет
- категория и регион
- дата и время регистрации
- число комментариев и групп
- процент лайков от ботов
- активность по дням
- закрытый ли аккаунт

С `-o` дополнительно создаются два файла: `*_comments.csv` (комментарии: ссылка, группа, дата) и `*_liked_bots.csv` (каким ботам аккаунт ставил лайки).

### Быстро проверить по скачанной базе

Этот способ не обращается к сайту, поэтому работает быстро и без лимитов:

```
python3 botnadzor.py check 3333 id2538 durov https://vk.com/id1
python3 botnadzor.py check --range 1-100000 --only-bots -o result.csv
```

### Обойти страницы списка

```
python3 botnadzor.py pages --start 1 --end 316 -o pages.csv
```

## Важно

- «Нет в базе» значит только, что Ботнадзор этот аккаунт не отметил, а не что аккаунт точно живой.
- Не делайте запросы к сайту слишком часто (`--delay` по умолчанию 1.5 с), иначе фаервол начнёт отвечать 403.
- Команда `check --access-code КОД` обращается к API расширения. Код выдаёт [@botnadzor_org_bot](https://t.me/botnadzor_org_bot).
